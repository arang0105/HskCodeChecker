# CLIP 품목분류 국내사례 — 요청 구조 (해독 완료)

조사일: 2026-08-18 · 방법: 브라우저 네트워크 관찰 + CLIP 자바스크립트 소스 직독

## 1. 결정례는 3계열이다

| 계열 | 성격 | URL 경로 조각 | `prlstClsfCaseTpcd` | `mttrTpcd` |
|---|---|---|---|---|
| **협의회결정사항** | **baseline 평가셋 출처** | `cncidtrm` | `03` | `02` |
| 위원회결정사항 | 관세품목분류위원회 | `cmitdtrm` | `04` | `01` |
| 품목분류사례 | 일반 사전심사 회신 | (없음) | `01` | (불필요) |

확인 근거: 평가셋 케이스 2(`품목분류2과-4144`, 정답 `3207209000`)를 결정세번 `3207.20-9000`으로
검색하면 **협의회에서만 1건** 나온다(2026-07-02). 품목분류사례·위원회는 0건.

`mttrTpcd` = 안건구분코드 (01:관세품목분류위원회, 02:품목분류협의회, 04:자체심의회)

**참조번호는 고유 식별자가 아니다** — 계열·연도에 걸쳐 재사용된다. 키는 `RRDC_NO`.

## 2. 엔드포인트

```
목록  POST /clip/prlstclsfsrch/{seg}/retrieveDmstPrlstClsfCaseLst2.do   → JSON
상세  POST /clip/prlstclsfsrch/{seg}/retrieveDmstPrlstClsfCaseDtl2.do   → HTML 조각
      (품목분류사례만 seg 없이 .../retrieveDmstPrlstClsfCaseDtl.do)
세션  GET  /clip/prlstclsfsrch/{seg}/openULS0203005S.do  ← 먼저 열어야 한다
```

**계열을 섞으면 빈 응답이 온다.** 품목분류사례 화면 세션으로 협의회 레코드 상세를 요청하면
값이 하나도 채워지지 않은 빈 표가 돌아온다. 에러가 아니라 빈 값이라 눈치채기 어렵다.

## 3. 필수 헤더

```
X-Requested-With: XMLHttpRequest
isAjax: true              ← 없으면 JSON 대신 "프로그램오류발생" HTML 페이지가 온다
User-Agent: (브라우저 문자열)
```

## 4. 목록 파라미터

| 파라미터 | 값 |
|---|---|
| `prlstClsfCaseTpcd` | **필수.** 계열 코드 (위 표) |
| `stDt` / `edDt` | 시행일자 범위 `2026-01-01` 형식. **반드시 준다** |
| `pagePerRecord` / `initPageIndex` | 페이지당 건수 / 페이지 번호 |
| `srchYn`=`Y`, `scrnTp`=`WDTH` | 고정 |
| `reffNo` `dtrmHsSgn` `cmdtNm` `cmdtDesc` `dtrmRsnCn` `srwr` | 선택 검색 조건 (빈 문자열로라도 보낸다) |

응답: `uls_dmst.thisTotalCount`, `uls_dmst.itemList[]`
필드: `RRDC_NO` `REFF_NO` `ENFR_DT` `CSTM_NM` `DTRM_HS_SGN` `CMDT_NM` `CMDT_DESC` `DTRM_RSN_CN` `IMGE_CNT`

## 5. 함정 — 목록의 텍스트는 176자에서 잘린다

`CMDT_DESC`와 `DTRM_RSN_CN`은 목록 응답에서 **176자로 절단**된다. `scrnTp`를 바꿔도 같다.
평가셋 29건 중 **23건이 176자를 넘는다**(중앙값 302자, 최대 1,306자).
→ **원문은 상세 호출로만 얻을 수 있다.**

상세 파라미터: `rrdcNo` + `mttrTpcd` (품목분류사례는 `rrdcNo`만)
상세 응답은 `<th>라벨</th><td>값</td>` 표. 라벨:
참조번호 / 시행일자 / 시행기관 / 결정세번 / 품명 / **물품설명** / **결정사유** / 이미지건수 / 관련 이미지

검증 결과 (평가셋 케이스 2): 물품설명 **205자**, 결정사유 **783자** — 온전하다.

## 6. 그 밖의 함정

- **조건 없는 전체 조회를 하면 브라우저가 멈춘다.** 반드시 시행일자 범위로 좁힌다
- 결정세번 표기가 `3207.20-9000` — 원문과 정규화값을 둘 다 남긴다
- `robots.txt`는 `/csp/`만 차단. `/clip/`은 허용
